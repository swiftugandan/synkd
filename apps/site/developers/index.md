# Developer docs

These pages are for people who write parties and client apps.

## What you will learn

- how to run synkd on your machine
- how to create a project with the CLI
- how to write a party class
- how to connect with partysocket
- how to add a Yjs collaborative pad
- which packages to import
- what works on Node versus a Durable Objects host
